The First C Project
<br>
This is a personal programming project built from scratch to learn the C language and explore advanced game mechanics. The game has evolved through two main development phases:
* **Version 1.0:** The project originally launched with a basic, hard-coded 20x20 maze grid. The map layout, character spawn points, and exit coordinates were completely static. This initial version served as a practical way to master the core fundamentals of 2D arrays, nested loops, and basic keyboard input handling in a terminal environment.
* **Version 2.0:** The architecture received a major upgrade to handle dynamic scaling and procedural generation. The static matrix was replaced with **dynamic memory allocation (`malloc` and `free`)**, allowing the grid dimensions to physically expand every time a player levels up. To generate unique maps, a **Randomised Depth-First Search (DFS) algorithm** was integrated. This generator utilizes **recursive backtracking** to carve through a solid grid of walls, ensuring every single level layout is completely unique, procedural, and guaranteed to be fully solvable. Additionally, an arcade layer was introduced to track total player moves alongside a strict 3-strikes health system that resets progress back to Level 1 upon failure.
